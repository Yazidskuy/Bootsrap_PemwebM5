1. Pengertian Bootstrap 
Bootstrap adalah framework CSS dan JS untuk membuat tampilan web yang responsif dengan cepat dan mudah. Kita tidak perlu menulis CSS dari awal karena sudah ada komponen bawaannya

2. Memasang Bootstrap 
Cara pakainya ada beberapa macam: 
- Pakai link CDN (ditempel di HTML)
- Download file Bootstrap lalu dipanggil secara lokal
- Install pakai package manager seperti npm

3. Grid dan Breakpoint 
- Grid: Sistem untuk bagi layar jadi 12 kolom supaya elemen gampang diatur posisinya
- Breakpoint: Titik batas ukuran layar (misal sm, md, lg) untuk ngatur kapan desain web harus berubah ngikutin ukuran HP, tablet, atau laptop
  
4. Class Bootstrap 
- container: Bikin wadah konten yang posisinya ada di tengah layar
- row: Bikin baris baru buat naruh kolom
- col: Bikin kolom di dalam baris
- btn btn-primary: Bikin desain tombol warna biru
- form-control: Bikin inputan form jadi rapi dan lebarnya full

5. Gambar Responsif
Tinggal tambahin class img-fluid di dalam tag `<img src="...">`
